# OpenDFe

Biblioteca .NET aberta para documentos fiscais eletrônicos brasileiros (NF-e e NFC-e; CT-e e MDF-e depois): geração do XML, validação pelas regras da SEFAZ, assinatura, transmissão, leitura e eventos.

**Em projeto.** Nada implementado ainda. A proposta está em [`docs/PROJETO.md`](docs/PROJETO.md).
