## Decisões (todas aprovadas pela recomendação)

1. **Pacotes:** `QuestPDF` e `QRCoder` (MIT, sem dependências nativas próprias), em `src/OpenDFe.Impressao.Pdf`. **Versões:** a última estável de cada uma **publicada há pelo menos 14 dias** (consulte a API do NuGet: `https://api.nuget.org/v3-flatcontainer/<id minúsculo>/index.json` e a data em `https://api.nuget.org/v3/registration5-gz-semver2/<id>/index.json`, ou `dotnet package search <id> --exact-match --format json`), fixas em `Directory.Packages.props` (`ManagePackageVersionsCentrally`). Registre a escolha e a data em `docs/NTS.md` ou no `PLANO.md`. O `ConferirPacotes.ps1` passa a esperar `OpenDFe.Nucleo`, `QuestPDF` e `QRCoder` como dependências do pacote `OpenDFe.Impressao.Pdf`.
2. **O QR Code vai ao PDF como SVG vetorial:** `QRCoder` gera a matriz (`QRCodeGenerator.CreateQrCode(texto, ECCLevel.M, forceUtf8: true)`; **nível M e UTF-8, como o manual do DANFE NFC-e manda**), e a lib monta o SVG (um retângulo por módulo, ou um `path` único, com `shape-rendering="crispEdges"`, **sem borda automática**: a quiet zone de 4 módulos é desenhada pelo componente que a usar) e o entrega ao QuestPDF por `.Svg(...)`. Nada de bitmap: vetor imprime nítido em qualquer resolução. Se o `Svg` do QuestPDF da versão escolhida não renderizar o SVG simples assim (não deve), registre e use `QuestPDF.Skia`/o desenho por canvas que a versão oferecer.
3. **O código de barras é Code 128 conjunto C (pares de dígitos), escrito pela lib** (a chave de 44 dígitos é só dígitos; o conjunto C a codifica em 22 símbolos), com o SVG gerado pela lib. Escreva o codificador (tabela dos 107 padrões, símbolo de início C, dígito verificador módulo 103, símbolo de fim) como classe interna, **testada contra vetores conhecidos** (por exemplo: `"1234"` = início C (105), 12, 34, verificador `(105 + 12×1 + 34×2) mod 103 = 82`, fim; sequência de barras e espaços da tabela padrão do Code 128) e contra um **decodificador escrito no teste** que lê a sequência de larguras de volta e recompõe o texto. Número ímpar de dígitos: a classe recusa (`ArgumentException`); quem usa já tem 44.
4. **A imagem de 1 bit:** a representação interna (largura, altura, bits empacotados MSB primeiro, 1 = preto) é o que a 7.2 vai expor no modelo neutro. Aqui, só a conversão para SVG (corridas horizontais de pixels pretos por linha, um `rect` por corrida, ou um `path`), com teste de ida e volta (a imagem → SVG → a matriz de pixels).
5. **A API pública desta etapa é mínima:**

```csharp
namespace OpenDFe.Impressao.Pdf;

/// O renderizador PDF do modelo de impressão (7.4). Nesta versão, só o diagnóstico.
public static class RenderizadorPdf
{
    /// Gera um PDF de uma página A4 com texto acentuado, um Code 128, um QR Code e uma imagem de 1 bit: serve para conferir
    /// que o pacote, a licença do QuestPDF e as fontes funcionam no ambiente. InvalidOperationException: a licença do
    /// QuestPDF não foi definida (a mensagem aponta o README do pacote).
    public static byte[] GerarPaginaTeste();
}
```

   O pacote **não define** `QuestPDF.Settings.License` (estado global e escolha do aplicativo, `PROJETO.md` 10.2). Antes de gerar, ele confere `QuestPDF.Settings.License`: se for nula, lança `InvalidOperationException` com uma mensagem em português que diz (a) que o QuestPDF exige a escolha de uma licença, (b) o código (`QuestPDF.Settings.License = QuestPDF.Infrastructure.LicenseType.Community;`) e (c) o endereço do README do pacote no GitHub (`https://github.com/Davidsonrf1/OpenDFe/blob/main/src/OpenDFe.Impressao.Pdf/README.md`). A checagem é uma classe interna reaproveitada pelos outros pontos de entrada da 7.4. **Fontes:** use a fonte embutida padrão do QuestPDF (Lato), que cobre o português; não registre fonte nenhuma (o `FontManager` é global) e documente, no README, como o aplicativo registra a dele se quiser.
6. **O projeto de testes novo:** `tests/OpenDFe.Impressao.Pdf.Testes` (xUnit v3, `*.Testes` ⇒ executável), referenciando o `OpenDFe.Impressao.Pdf`, adicionado ao `OpenDFe.slnx`. O teste define a licença **uma vez** (inicializador de módulo do assembly de teste: `QuestPDF.Settings.License = LicenseType.Community;`), e um teste separado prova a mensagem de licença não definida **sem estado global compartilhado**: se não der para zerar o `Settings.License` com segurança, isole esse teste numa coleção/ordem própria ou em um executável de teste à parte e explique no comentário. Leitura do PDF nos testes: `UglyToad.PdfPig` (Apache-2.0), dependência **só de teste** (versão como na decisão 1), para conferir cabeçalho, número de páginas, tamanho da página, o texto extraído (com acentos) e a presença das imagens/vetores.
7. **O README do pacote** (`src/OpenDFe.Impressao.Pdf/README.md`, empacotado: `PackageReadmeFile`), com **a licença no primeiro bloco, antes de qualquer outra coisa**: o aviso de que o QuestPDF tem licença própria (Community para projetos open source, pessoas físicas e empresas abaixo do limite de receita anual; acima dele, quem usa compra a licença), que a obrigação é de **quem usa** o `OpenDFe.Impressao.Pdf`, não da OpenDFe, o texto e a data da conferência no site oficial e o link; depois: o que o pacote faz, como definir a licença (`LicenseType.Community` ou a comercial), o erro que aparece sem ela, o que o aplicativo ESC/POS (o PDV) **não** precisa deste pacote (carrega só o núcleo e o leiaute), o requisito no Linux (confirmar na documentação da versão: as bibliotecas do sistema que o Skia pede, como `libfontconfig`, e como instalar), as fontes, e a nota de terceiros (QuestPDF, QRCoder: nome, licença, link). Mantenha o texto curto e exato.

## Testes

- `CodigoBarras128Testes`: vetores conhecidos; as 100 combinações de pares `00` a `99` contra a tabela; a chave de 44 dígitos (22 símbolos + início + verificador + fim = 25 símbolos; largura total em módulos 11×24 + 13 = 277... **confira o número pela tabela, não por este texto**); o decodificador de teste ida e volta com chaves aleatórias (semente fixa); a recusa de caractere não numérico e de quantidade ímpar.
- `QrCodeSvgTestes`: a matriz do SVG é igual à `ModuleMatrix` do QRCoder (leia o SVG de volta); o nível M e UTF-8 (um texto com acento e uma URL de NFC-e de verdade, versões 2 e 3, geram versões de QR compatíveis: nível M); sem borda.
- `ImagemBitSvgTestes`: ida e volta; imagem toda branca, toda preta, 1×1, largura não múltipla de 8.
- `RenderizadorPdfTestes` (com o PdfPig): `GerarPaginaTeste` devolve um PDF (`%PDF-`), uma página A4, com os acentos no texto extraído, e contém os elementos gráficos; a geração é repetível em paralelo (8 chamadas simultâneas, sem exceção); a licença não definida (mensagem com o endereço do README).
- **Linux:** esta é a etapa em que o Linux importa mais (Skia nativo): rode no WSL se houver; senão, registre "Linux não conferido (sem WSL); o `ci.yml` cobre" e **verifique que o `ci.yml` cobre** (o job de testes roda o projeto novo, e o `ubuntu-latest` tem o que o Skia precisa; se precisar de pacote apt, ponha no job).
- **Mutação provada:** o verificador do Code 128 errado; o QR Code com o nível L; a licença não checada.
