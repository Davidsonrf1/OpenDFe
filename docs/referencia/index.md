# Referência da API

A referência lista todos os tipos e membros públicos da OpenDFe, organizados por namespace. Para aprender a usar a biblioteca, comece pelos [guias](../index.md); volte aqui para consultar a assinatura e o comportamento exato de um membro.

> **Observação**
> As páginas desta seção são geradas por `eng/GerarReferencia.cs` a partir dos comentários XML do código-fonte. Para atualizá-las, compile em Release (`dotnet build OpenDFe.slnx -c Release`) e rode `dotnet run eng/GerarReferencia.cs` na raiz do repositório.
